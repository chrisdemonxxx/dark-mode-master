# Dark Mode Master — Free Dark Mode for All Websites

Free dark mode browser extension. Works on every website. Save your eyes during late-night browsing.

## Features
- 🌙 One-click dark mode toggle
- 🎨 Customizable brightness & contrast
- ⚡ Smart color inversion (preserves images)
- 📋 Site whitelist (disable on specific sites)
- 🔋 Battery-efficient rendering
